# NovaPOS — симулятор платёжного терминала

Интерактивный платёжный POS-терминал в браузере с журналом операций в бесплатной базе данных SQLite.

## Возможности

- **Оплата картой** (бесконтактно) — три тестовые карты: успешная, «недостаточно средств», с обязательным PIN
- **PIN-код** — запрашивается для сумм свыше 3 000 ₽; тестовый PIN: `1234`
- **Наличные** — ввод полученной суммы и расчёт сдачи
- **Оплата по QR-коду** (СБП) — симуляция оплаты клиентом
- **Возвраты** — по номеру операции через меню терминала или из журнала
- **Смены** — X-отчёт (итоги) и Z-отчёт (закрытие смены)
- **Чек** с анимацией печати и выводом на принтер
- Звуковые сигналы, управление с клавиатуры (цифры, Enter, Backspace, Esc, `M` — меню)
- Светлая и тёмная тема, адаптивная вёрстка под телефон

## База данных

Бесплатная, без сервера и регистрации: SQLite работает в браузере через
WebAssembly ([sql.js](https://github.com/sql-js/sql.js)), а данные сохраняются в IndexedDB.
Таблицы:

- `shifts` — смены (открытие, закрытие)
- `transactions` — операции: тип, способ оплаты, сумма (в копейках), статус, карта, код авторизации, RRN, сдача, ссылка на исходную операцию для возврата

Кнопка «Скачать базу» сохраняет файл `novapos.db`, который открывается любым SQLite-клиентом
(например, DB Browser for SQLite).

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → выбрать ветку и папку `/ (root)` → Save.
Через минуту сайт будет доступен по адресу `https://<пользователь>.github.io/novafpos/`.

> Это учебный симулятор: реальные платежи не проводятся, чеки не являются фискальными документами.
